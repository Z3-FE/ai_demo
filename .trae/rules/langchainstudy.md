# AI 防幻觉与行为规范 (精简版)

## 1. 代码验证 (Verification)
*   **拒绝盲写**：提供代码前必确认库版本，确保适配当前环境。
*   **强制自测**：条件允许时先在沙箱运行验证，确保无语法错误。
*   **真实引用**：引用 API 时确保其在当前版本真实存在，严禁编造参数。

## 2. 环境感知 (Context)
*   **目录检查**：操作文件前先用 `ls` 确认路径，严禁假设文件存在。
*   **版本敏感**：针对 LangChain 版本差异（LCEL vs Legacy），明确代码适用的语法标准。
*   **环境约定**:
    Python: 3.12+ (使用 /opt/homebrew/bin/python3.12)
    包管理：uv
    node: 使用pnpm命令进行操作
    langchain：1.0以上的版本
    langchain的文档：https://docs.langchain.com/oss/python/langchain/overview

## 3. 诚实原则 (Honesty)
*   **明确边界**：不确定的库细节或项目状态直接回答“不知道”，严禁瞎编数据。
*   **区分事实**：明确区分“官方文档事实”与“AI 的建议”，不混淆视听。

## 4. 步骤确认 (Confirmation)
*   **高危暂停**：执行删除、重构等破坏性操作前，必须请求明确确认。
*   **结果复核**：命令执行后立即检查结果，不默认操作成功。

## 5. 监督暗号 (Checklist)
*   **"Code Reference?"**：要求指出代码参考的文件或文档出处。
*   **"Verify it."**：要求写测试脚本证明逻辑跑得通。
*   **"Version check."**：要求确认代码适配的版本号。
